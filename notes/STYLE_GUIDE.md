Poetry Style Guide - Test5 Collection

Purpose

The style guide exists to maintain consistency across poems added to the Test5 repository, making contributions easier to review and ensuring a cohesive presentation.

File Naming
- Use lowercase and underscores: "summer_breeze.txt"
- Avoid spaces or special characters

File Format
- Use UTF-8 plain text (.txt)
- Start with a title line, then a blank line, then poem body
- Optionally include metadata (Author, Date) as a small header

Formatting Rules
- Keep line lengths reasonable (60-80 characters preferred) for readability
- Use blank lines between stanzas
- Use standard English punctuation and capitalization unless intentional
- Preserve intentional stylistic choices made by poets

Metadata Example
Title
Author: Jane Doe
Date: 2026-04-24

(Blank line)

Poem body...

Accessibility
- Ensure poems are readable in plain text readers
- Avoid non-standard fonts or special formatting

Contribution Notes
- When adding multiple poems, create a poems/ directory
- Update README.md or DOCUMENTATION.md with new entries
